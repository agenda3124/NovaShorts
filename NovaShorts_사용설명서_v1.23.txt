NovaShorts v1.23 사용 안내

[핵심 수정]
- 쿠팡 상품 분석 후 영상 검색창만 열리고 실제 결과가 0건인데 마지막에 '유사도 미달'로 보이던 문제를 분리했습니다.
- 영상이 0건이면 유사도 계산을 하지 않고 플랫폼별 수집 건수/상태를 표시합니다.
- 검색 페이지 고정 4~5초 대기 대신 실제 링크 수가 안정될 때까지 최대 약 10~14초 기다립니다.
- 검색 결과를 스크롤하며 추가 로딩하고, Google 사이트 검색 리다이렉트 URL을 실제 플랫폼 URL로 복원합니다.
- 동시에 여는 플랫폼 수를 4개에서 2개로 줄여 빈 탭/팝업이 한꺼번에 뜨는 현상을 줄였습니다.
- 검색어를 한 번만 쓰지 않고 모델명 → 브랜드+모델 → 플랫폼별 보조 검색어 순으로 자동 재시도합니다.
- Gemini API 키가 있으면 다국어 검색어를 추가하고, 없어도 브랜드/모델 식별 토큰 기반 폴백으로 검색합니다.

[상품 주소 자동 제작]
1. 상품 주소 입력
2. 입력 내용 확인
3. 영상 만들기 시작
4. 상품명/브랜드/모델 분석
5. 7개 플랫폼 검색어 생성
6. TikTok/YouTube/Instagram/Douyin/小红书/Kuaishou/1688 자동 수집
7. 플랫폼별 수집 건수 표시
8. 수집된 영상에 대해서만 상품 관련도 계산
9. 관련도 기준 통과 후보 자동 선택
10. 다운로드 → 자막/OCR → 분석/번역 → TTS → 재편집 → 최종 영상

[검색 결과 0건일 때]
- 팝업에 TikTok 0건 / YouTube 0건 / ... 식으로 실제 수집 건수가 표시됩니다.
- '로그인/인증 확인'이면 NovaShorts가 자동으로 연 전용 Chrome/Edge 창에서 해당 플랫폼에 로그인한 뒤 다시 시도하세요.
- '접근 차단'이면 전용 브라우저에서 검증 화면을 직접 완료한 뒤 다시 시도하세요.
- '결과 없음'이면 자동으로 다른 검색어와 외부 사이트 검색까지 재시도한 뒤에도 결과가 없었다는 뜻입니다.

[Gemini API]
- 필수는 아닙니다.
- 브랜드/모델이 명확한 상품은 API 없이도 검색합니다.
- 한국어 상품명만 있고 모델명이 없는 상품은 설정의 Gemini API Key를 넣으면 중국 플랫폼용 중국어 검색어와 영문 플랫폼 검색어 품질이 좋아집니다.

[중요]
- 최소 유사도를 낮추는 것은 영상 수집 0건 문제의 해결책이 아닙니다.
- v1.23은 수집 0건과 실제 유사도 미달을 서로 다른 오류로 표시합니다.
