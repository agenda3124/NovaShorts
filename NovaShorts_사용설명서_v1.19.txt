NovaShorts v1.19 사용설명서
============================

1. 가장 중요한 변경
------------------
- 제품명만 입력해도 관련 영상 소싱을 시작할 수 있습니다.
- 쿠팡/상품 URL을 붙여넣으면 상품 페이지의 상품명, 브랜드, 모델명, 대표 이미지를 분석한 뒤 영상 소싱으로 이어집니다.
- URL 분석은 쿠팡 API 키가 없어도 먼저 동작합니다.
- 쿠팡 Access/Secret Key는 '쿠팡 API 보강' 기능을 쓸 때만 필요합니다.
- 수집 후보는 제목 관련도와, 가능한 경우 상품 대표 이미지-영상 썸네일 유사도를 함께 계산합니다.
- 일반 yt-dlp 다운로드가 실패하면 Chrome Bridge가 현재 공개 페이지에서 재생 가능한 미디어 URL을 찾아 한 번 더 다운로드를 시도합니다.

2. Chrome Bridge 설치/갱신
------------------------
1) NovaShorts ZIP을 새 폴더에 압축 해제합니다.
2) Chrome 주소창에 chrome://extensions 를 입력합니다.
3) 우측 상단 '개발자 모드'를 켭니다.
4) '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5) NovaShorts 폴더 안 browser-extension 폴더를 선택합니다.
6) 기존 NovaShorts Bridge가 설치되어 있으면 반드시 새 browser-extension 폴더로 다시 로드/갱신합니다.
7) 확장 프로그램 팝업에서 NovaShorts 설정에 표시되는 Bridge Token을 연결합니다.

v1.19 확장 프로그램은 TikTok, YouTube, Instagram, Douyin, Xiaohongshu, Kuaishou, 1688 및 쿠팡 상품 페이지를 지원합니다.

3. 제품명으로 소싱
-----------------
1) 왼쪽 '소싱'을 누릅니다.
2) '상품명 · 브랜드 · 모델명' 칸에 제품명을 입력합니다.
3) '제품명 소싱 시작'을 누릅니다.
4) Gemini 검색계획이 켜져 있으면 국가/플랫폼에 맞는 검색어를 생성합니다. API 키가 없거나 Gemini 검색계획을 끄면 규칙 기반 검색어를 사용합니다.
5) 연결된 Chrome Bridge가 각 플랫폼 검색 페이지를 열고 공개 영상 후보 링크와 썸네일을 수집합니다.
6) 후보는 관련도 높은 순서로 정렬됩니다.

4. 쿠팡/상품 URL로 소싱
---------------------
1) '쿠팡/상품 URL' 칸에 링크를 붙여넣습니다.
2) 'URL 분석 · 소싱'을 누릅니다.
3) NovaShorts가 먼저 일반 HTTP 페이지에서 상품 메타데이터를 분석합니다.
4) 페이지 정보가 부족하고 Chrome Bridge가 연결되어 있으면 실제 브라우저에서 보이는 페이지를 열어 JSON-LD/OG 메타데이터를 다시 분석합니다.
5) 상품명/브랜드/모델/대표 이미지가 확보되면 자동으로 검색어를 만들고 플랫폼 영상 수집으로 이어집니다.

중요: 쿠팡 사이트 정책/페이지 구조/로그인 상태에 따라 정적 분석이 막힐 수 있습니다. 이 경우 Chrome Bridge가 설치되고 연결되어 있어야 브라우저 분석 폴백이 동작합니다.

5. 쿠팡 API 보강
---------------
- 필수 기능이 아닙니다.
- 설정에 Coupang Access Key / Secret Key를 입력한 경우에만 사용합니다.
- 상품명으로 쿠팡 파트너스 검색 API를 호출해 상품명과 대표 이미지를 보강합니다.
- API 키가 없어도 URL 분석·소싱은 사용할 수 있습니다.

6. 관련도 계산
-------------
NovaShorts는 다음 정보를 사용합니다.
- 상품명
- 브랜드
- 모델명
- 영상 후보 제목
- 영상 후보 썸네일(수집된 경우)
- 상품 대표 이미지(추출된 경우)

모델명이 영상 제목에 정확히 포함되면 높은 관련도를 부여합니다. 대표 이미지와 후보 썸네일이 모두 있는 경우 이미지 perceptual hash 유사도도 함께 사용합니다.

'저유사도 자동 제외'가 켜져 있더라도 모든 후보가 기준 미달이면 상위 몇 개를 '기준미달/검토' 상태로 남겨 검색결과 0건처럼 보이는 상황을 줄였습니다.

7. 영상 다운로드
---------------
1) 후보를 선택합니다.
2) '선택 영상 다운로드'를 누릅니다.
3) 먼저 yt-dlp 방식으로 다운로드합니다.
4) 실패하고 Chrome Bridge가 연결되어 있으면 공개 페이지에서 video/source/OG video/재생 리소스를 찾아 재시도합니다.
5) 성공한 영상은 편집/썸네일/업로드 화면에 자동 연결됩니다.

8. 편집
------
- OCR 스캔: Tesseract로 중국어/한국어/영어 자막을 스캔합니다.
- 자막 제거: 현재 버전은 하단 자막 영역 블러 방식입니다.
- 자동 컷: 목표 길이와 컷 길이를 기준으로 구간을 추출해 세로 쇼츠로 만듭니다.
- TTS: Edge TTS 음성을 생성합니다.
- 최종 렌더: 1080x1920 세로 영상으로 렌더합니다.
- 워터마크: 빠른 설정에서 ON/OFF 합니다.

9. 업로드/링크
-------------
- YouTube 업로드: 설정에서 본인의 client_secret.json을 지정해야 합니다.
- Lnk.Bio: Client ID/Secret이 있는 경우 링크를 추가할 수 있습니다.
- X: 게시문을 작성창으로 넘길 수 있습니다.

10. 문제 해결
------------
[Chrome Bridge가 연결되지 않음]
- chrome://extensions에서 NovaShorts Bridge를 새 버전 browser-extension 폴더로 다시 로드합니다.
- 확장 프로그램 팝업의 Bridge Token을 다시 확인합니다.
- NovaShorts를 재시작합니다.

[URL 분석 실패]
- 링크가 실제 상품 상세페이지로 연결되는지 브라우저에서 확인합니다.
- Chrome Bridge를 갱신합니다.
- 짧은 쿠팡 링크도 지원을 시도하지만 리다이렉트/로그인 페이지에 따라 실패할 수 있습니다.

[관련 영상 0건]
- 플랫폼을 모두 선택했는지 확인합니다.
- Chrome Bridge가 연결되어 있는지 확인합니다.
- 최소 유사도를 낮춰봅니다.
- 제품명에 브랜드/모델명을 같이 넣으면 정확도가 높아집니다.

[다운로드 실패]
- 영상이 공개 상태인지 확인합니다.
- 브라우저에서 실제 재생되는지 확인합니다.
- 사이트 로그인/지역 제한/DRM 영상은 자동 다운로드가 되지 않을 수 있습니다.

11. 개인정보/계정
----------------
- NovaShorts는 SSMaker 회원 인증을 사용하지 않습니다.
- 다른 프로그램의 로그인 토큰/비밀번호/라이선스 값을 복사하지 않습니다.
- 각 서비스 연동에는 사용자가 직접 발급한 API/OAuth 정보를 사용합니다.
