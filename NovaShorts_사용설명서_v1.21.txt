NovaShorts v1.21 사용설명서
============================

1. 핵심 변경
- 원본 프로그램 데모에서 확인된 사용 흐름을 기준으로 메인 화면을 다시 구성했습니다.
- 메인 화면에서 준비한 자료 유형을 먼저 선택합니다.
  ① 상품 주소
  ② 영상 1개
  ③ 여러 영상
  ④ 준비한 자료
- 필요한 경우에만 목소리 / 자막 / 편집 설정을 펼쳐서 조정합니다.
- 마지막에는 '영상 만들기 시작' 한 번으로 제작을 실행합니다.
- 완성 결과는 메인 화면에서 바로 재생하거나 결과 폴더를 열 수 있습니다.

2. 상품 주소 모드
- 쿠팡 또는 일반 상품 주소를 붙여넣습니다.
- '입력 내용 확인'을 누르면 상품명, 브랜드, 모델, 대표이미지를 확인합니다.
- 쿠팡이 일반 HTTP 요청을 403으로 막아도 프로그램이 Chrome/Edge를 자동으로 실행하여 실제 브라우저 페이지에서 다시 분석합니다.
- v1.21의 기본 동작에는 Chrome Bridge 확장 프로그램 토큰 입력이 필요하지 않습니다.
- 브라우저 자동 분석도 실패하고 기존 Bridge가 연결되어 있는 경우에만 Bridge를 보조 폴백으로 사용합니다.
- 상품 확인 후 '영상 만들기 시작'을 누르면 7개 플랫폼 검색 → 후보 관련도 정렬 → 상위 후보 다운로드 → 제작으로 이어집니다.

3. 영상 1개 모드
- 가지고 있는 영상 하나를 선택합니다.
- 상품명/주제를 입력하지 않으면 파일명을 기준으로 처리합니다.
- 영상 만들기를 누르면 OCR, 자막 제거, 음성분석, 대본, TTS, 컷 편집, 세로 렌더, 자막, 썸네일 단계가 설정에 따라 실행됩니다.

4. 여러 영상 모드
- 영상 여러 개를 추가합니다.
- 선택한 영상들을 공통 포맷으로 정리한 뒤 하나의 제작 소스로 연결합니다.
- 이후 자동 분석/대본/TTS/컷 편집/렌더 파이프라인을 실행합니다.

5. 준비한 자료 모드
- 직접 준비한 영상 자료를 하나 이상 추가합니다.
- 상품명/주제를 입력합니다.
- 이미 작성해 둔 한국어 대본이 있으면 대본 칸에 붙여넣습니다.
- 대본이 있으면 그대로 TTS/자막 타이밍에 사용하고, 비워두면 영상 분석 결과를 바탕으로 자동 작성합니다.

6. 제작 설정
- 목소리 설정: SunHi / InJoon / Hyunsu, 말하기 속도
- 자막 설정: 원본 자막 제거, 한국어 자막 삽입
- 편집 설정: 자동 컷 편집, 목표 길이, 썸네일 자동 생성, 워터마크
- 설정은 접힌 상태가 기본이며 필요한 항목만 펼쳐서 변경합니다.

7. 상품 영상 자동 소싱
- TikTok
- YouTube
- Instagram
- Douyin
- Xiaohongshu(小红书)
- Kuaishou
- 1688
- 프로그램이 플랫폼별 검색어를 생성하고 브라우저 자동제어(CDP)로 검색 페이지를 열어 후보 링크를 수집합니다.
- 제목/브랜드/모델/가능한 경우 대표이미지 정보를 이용해 후보를 정렬합니다.

8. 브라우저 자동 연결
- Chrome 또는 Edge가 설치되어 있으면 프로그램이 전용 NovaShorts 브라우저 프로필을 사용해 자동 연결합니다.
- 첫 실행 시 별도 브라우저 창이 열릴 수 있습니다.
- 사이트가 로그인, CAPTCHA, 추가 확인을 요구하면 열린 브라우저에서 사용자가 직접 완료한 뒤 다시 실행하세요.
- 자동화 우회나 CAPTCHA 자동해결은 사용하지 않습니다.

9. 전체 제작 단계
- 입력 자료 확인
- 상품 모드일 경우 관련 영상 자동 검색/선택/다운로드
- 여러 영상일 경우 소스 병합
- OCR 스캔
- 스마트 원본 자막 제거
- Whisper 음성 분석
- 한국어 쇼츠 대본 생성 또는 준비 대본 사용
- Edge TTS 생성
- 한국어 자막 타이밍 생성
- 자동 컷 편집
- 1080×1920 세로 렌더
- 한국어 자막 삽입
- 워터마크(선택)
- 썸네일(선택)
- YouTube/Lnk.Bio는 사용자가 설정에서 자동 기능을 켠 경우에만 실행

10. 중요
- 상품 주소만으로 항상 모든 플랫폼에서 동일 제품 영상이 존재하는 것은 아닙니다.
- 플랫폼 로그인/지역 제한/페이지 구조 변경으로 특정 플랫폼 수집이 실패할 수 있습니다.
- '관련 영상'은 상품정보와 후보 정보를 비교한 결과이며 최초 업로더를 보장하는 '원본 역추적 판정'과는 별도 기능입니다.
- 외부 업로드는 기본 OFF입니다.
