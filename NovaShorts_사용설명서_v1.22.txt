NovaShorts v1.22 사용설명서
============================

1. 핵심 사용법
-------------
메인 제작 화면에서 준비한 자료 형태를 먼저 선택합니다.

[상품 주소]
쿠팡/상품 URL → 입력 내용 확인 → 상품명/브랜드/모델/이미지 확인 → 영상 만들기 시작
→ 7개 플랫폼 관련 영상 수집 → 관련도 검증 → 영상 다운로드 → 전체 제작

[영상 1개]
영상 파일 1개 선택 → 필요하면 상품명/주제 입력 → 영상 만들기 시작

[여러 영상]
2개 이상 영상 추가 → 영상 만들기 시작
→ 각 영상을 분석한 뒤 장면을 분산 선택하여 하나의 쇼츠로 재편집합니다.

[준비한 자료]
영상 추가 → 상품명/주제 입력 → 준비한 한국어 대본이 있으면 붙여넣기
→ 비워두면 영상 분석 후 자동 대본을 만듭니다.

2. 제작 설정
------------
목소리 설정, 자막 설정, 편집 설정은 필요한 항목만 펼쳐 수정합니다.
선택한 목소리는 '선택한 목소리 미리듣기'로 확인할 수 있습니다.

기본값:
- 원본 자막 제거 ON
- 한국어 자막 넣기 ON
- 자동 컷 편집 ON
- 썸네일 자동 생성 ON
- 워터마크 OFF
- YouTube 자동 업로드 OFF
- Lnk.Bio 자동 링크 OFF

3. 상품 주소 처리
----------------
쿠팡이 일반 HTTP 분석을 403으로 차단해도 즉시 실패하지 않습니다.
NovaShorts는 다음 순서로 상품 정보를 확인합니다.
1) 공개 페이지 메타데이터
2) NovaShorts 전용 Chrome/Edge 프로필의 실제 페이지
3) 자동 페어링된 NovaShorts Bridge 확장 프로그램 폴백

Chrome Bridge Token을 사용자가 직접 복사할 필요가 없습니다.
NovaShorts가 실행 중이면 v1.22 확장 프로그램이 로컬 Bridge와 자동 페어링됩니다.

4. 글로벌 영상 소싱
-------------------
지원 플랫폼:
- TikTok
- YouTube
- Instagram
- Douyin
- 小红书(Xiaohongshu)
- Kuaishou
- 1688

상품명/브랜드/모델을 기준으로 플랫폼별 검색어를 생성합니다.
Gemini API Key가 있으면 플랫폼 언어에 맞게 검색어를 보강하고, 없으면 규칙 기반 검색어로 계속 동작합니다.
후보는 상품명/브랜드/모델/가능한 경우 대표이미지 관련도로 정렬합니다.
최소 유사도 이하 후보 자동 제외가 켜져 있으면 잘못된 제품 영상을 임의로 자동 선택하지 않습니다.

----------------------
입력 영상 검증
→ 포맷 정규화
→ OCR 화면 자막 탐지

→ 대본 사실성 검증
→ 한국어 TTS 생성
→ 목표 길이에 TTS 속도 자동 맞춤
→ 한국어 SRT 자동 분할
→ 단일/다중 영상 장면 재편집
→ 1080×1920 최종 합성

→ 최종 영상/오디오/해상도 무결성 검사

→ 게시용 제목/설명/태그 생성
→ 설정이 켜진 경우만 YouTube/Lnk.Bio 실행

6. 설정 > 원본 분석 대응 기능
-----------------------------
다음 기능은 v1.22에서 실제 제작 파이프라인에 연결되어 있으며 기본 ON입니다.
- 영상 장면 분석
- 음성 분석
- 원문 → 한국어 번역
- 대본 사실성 검증
- AI 대본 검증 보강
- TTS 길이 자동 맞춤
- 다중소스 재편집
- 최종 영상 무결성 검증
- 렌더 오류 자동 복구

7. API / 계정
-------------
Gemini API Key:
없어도 기본 제작은 가능하지만 검색어/번역/대본/검증 품질 보강에 사용합니다.

쿠팡 API Access/Secret:
상품 URL 분석 및 영상 소싱의 필수값이 아닙니다. 쿠팡 API 상품 검색 보강 기능에만 사용합니다.

YouTube client_secret.json:
YouTube 자동 업로드를 사용할 때만 필요합니다. 첫 OAuth 이후 토큰을 재사용합니다.
자동 업로드는 기본 OFF입니다.
댓글 작성 옵션을 켜면 업로드 완료 후 댓글을 작성할 수 있습니다. 자동 '고정(pin)'은 하지 않습니다.

Lnk.Bio:
Client ID/Secret이 있고 자동 링크를 ON으로 설정한 경우에만 실행합니다.

8. API 키 저장
--------------
v1.22는 가능한 Windows 환경에서 keyring/Windows 자격 증명 저장소를 사용합니다.
기존 settings.json의 키가 있으면 자격 증명 저장소로 마이그레이션을 시도합니다.
운영체제 keyring을 사용할 수 없는 환경에서는 기존 설정 파일 방식으로 폴백합니다.
API Key/Secret/Bridge Token은 다른 사람에게 공유하지 마세요.

9. 결과 확인
------------
완성되면 메인 제작 화면에서 결과 상태를 확인하고 즉시 재생하거나 결과 폴더를 열 수 있습니다.
각 작업 폴더에는 다음과 같은 진단 파일이 저장됩니다.
- subtitle_detection.json
- transcripts.json
- analysis.json
- script.txt
- script_validation.json
- render_integrity.json
- publish_metadata.json
- result.json

10. 원본 SSMaker 기능 대응 근거
-----------------------------
배포 폴더의 SSMaker_기능대응표_v1.22.md를 확인하세요.
사용자가 제공한 SSMaker 설치 트리/실행 흔적/작동 영상에서 확인된 기능 단위와 NovaShorts 구현 위치를 1대1로 정리했습니다.
비공개 .pyd 내부 알고리즘을 복사한 것이 아니라 확인 가능한 기능 범주를 독립 구현한 clean-room 대응입니다.

11. 주의사항
------------
- 플랫폼의 공개 웹 구조가 바뀌면 수집 셀렉터 보완이 필요할 수 있습니다.
- 로그인 필요한 플랫폼은 NovaShorts 전용 브라우저에서 사용자가 직접 로그인을 완료한 뒤 세션을 재사용합니다.
- CAPTCHA/로그인/라이선스 우회 기능은 사용하지 않습니다.
- 원본 영상 사용 권리와 플랫폼 정책을 확인한 뒤 사용하세요.
