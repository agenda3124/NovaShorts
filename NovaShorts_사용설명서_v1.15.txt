NovaShorts v1.15 상세 사용설명서
================================

0. 이 설명서의 기준
------------------
이 설명서는 NovaShorts v1.15 Windows 빌드를 기준으로 작성되었습니다.
현재 프로그램은 다음 기능을 한 화면 흐름으로 연결합니다.

- 상품명/키워드 입력
- Gemini 또는 규칙 기반 검색어 생성
- TikTok / YouTube / Instagram / Douyin / Xiaohongshu / Kuaishou / 1688 검색
- Chrome Bridge를 통한 후보 링크 수집
- 후보 유사도 계산 및 낮은 유사도 자동 제외
- yt-dlp 영상 다운로드
- Tesseract OCR 자막 탐지
- 하단 자막 영역 정리(블러 방식)
- Edge TTS 한국어 음성 생성
- 1080×1920 세로형 영상 렌더링
- 자동 컷 편집
- 워터마크
- 썸네일 생성
- YouTube OAuth 업로드
- Lnk.Bio 링크 추가
- X 작성창 열기
- 작업 대기열/진행 상태/런타임 진단

중요: 플랫폼 사이트의 로그인 상태, 지역 제한, 사이트 구조 변경, CAPTCHA, 개별 영상의 다운로드 허용 여부 등에 따라 소싱/다운로드 결과가 달라질 수 있습니다.


1. 압축 해제와 실행
------------------
1) NovaShorts_v1.15.zip을 원하는 폴더에 압축 해제합니다.
2) 압축 해제한 폴더의 NovaShorts.exe를 실행합니다.
3) 실행이 막히면 START_NovaShorts.bat을 실행해도 됩니다.
4) 최초 실행 시 사용자 폴더에 아래 폴더가 자동 생성됩니다.

   C:\Users\사용자이름\.novashorts\

5) 주요 저장 파일
   - settings.json : 프로그램 설정
   - logs\novashorts.log : 실행/오류 로그

6) 기본 결과 저장 폴더
   C:\Users\사용자이름\Videos\NovaShorts


2. 화면 구성
------------
왼쪽 메뉴
- 홈: 빠른 소싱 시작
- 소싱: 검색어 생성, 플랫폼 선택, 후보 수집, 유사도 계산, 다운로드
- 편집: OCR, 자막 정리, 자동 컷, 최종 렌더
- AI 음성: Edge TTS 음성 생성
- 썸네일: 영상 프레임 + 문구로 썸네일 생성
- 업로드: YouTube 업로드
- 링크 관리: Lnk.Bio / X
- 설정: API 키, 출력 폴더, 유사도, 연동 정보

오른쪽 빠른 설정
- AI 모델
- TTS 음성
- 영상 해상도
- 자막 제거 (OCR) ON/OFF
- 자동 컷 편집 ON/OFF
- 워터마크 추가 ON/OFF
- 업로드 후 링크 생성 ON/OFF
- 미리보기

아래 작업 대기열
- 실행 중인 작업명
- 상태
- 진행률
- 시작 시간
- 완료/실패 표시


3. 처음 실행 후 가장 먼저 할 설정
-------------------------------
왼쪽 메뉴에서 [설정]을 엽니다.

3-1. 출력 폴더
- 결과 영상, TTS, 썸네일 등을 저장할 기본 폴더입니다.
- 기본값 그대로 사용해도 됩니다.

3-2. Gemini API Key
- AI 검색어 생성에 사용합니다.
- 비워두면 프로그램은 규칙 기반 검색어 생성으로 자동 대체합니다.
- 빠른 설정의 AI 모델을 '규칙 기반'으로 바꾸면 Gemini 없이도 검색 계획을 만들 수 있습니다.

3-3. Coupang Access Key / Secret Key
- 쿠팡 API 검색 버튼을 사용할 때만 필요합니다.
- 쿠팡 API를 사용하지 않고 상품명/키워드만 직접 입력해 소싱할 수도 있습니다.

3-4. 최소 유사도
- 기본값 55
- 상품명과 수집 후보 제목을 비교해서 0~100 점으로 계산합니다.
- 값이 높을수록 더 엄격하게 후보를 거릅니다.
- 너무 결과가 적으면 35~45 정도로 낮춰 테스트하세요.

3-5. 저유사도 자동 제외
- 체크: 설정한 최소 유사도보다 낮은 제목 후보를 자동 제외
- 해제: 낮은 유사도 후보도 목록에 표시

3-6. YouTube client_secret.json
- YouTube 업로드 기능을 쓸 때 필요합니다.
- Google Cloud Console에서 YouTube Data API용 OAuth 데스크톱 앱 클라이언트 파일을 받아 경로를 지정합니다.

3-7. Lnk.Bio Client ID / Client Secret
- Lnk.Bio 자동 링크 추가 기능을 사용할 때 필요합니다.

설정을 입력한 뒤 반드시 [설정 저장]을 누르세요.


4. Chrome Bridge 확장 프로그램 연결
----------------------------------
NovaShorts는 플랫폼 검색 페이지에서 후보 링크를 수집하기 위해 로컬 Chrome Bridge를 사용할 수 있습니다.

4-1. 확장 프로그램 설치
1) Chrome 또는 Edge 주소창에서 확장 프로그램 관리 화면을 엽니다.
2) 개발자 모드를 켭니다.
3) [압축해제된 확장 프로그램을 로드]를 누릅니다.
4) NovaShorts 폴더 안의 browser-extension 폴더를 선택합니다.

4-2. Bridge Token 입력
1) NovaShorts를 한 번 실행합니다.
2) 아래 파일을 메모장으로 엽니다.

   C:\Users\사용자이름\.novashorts\settings.json

3) bridge_token 항목의 값을 복사합니다.
4) 브라우저의 NovaShorts 확장 프로그램 아이콘을 누릅니다.
5) Token 입력칸에 붙여넣고 저장합니다.
6) '연결됨'이라고 표시되면 정상입니다.

Bridge 주소
- 127.0.0.1:38471

주의
- bridge_token은 본인 PC의 NovaShorts 로컬 브리지 인증용 값입니다.
- 다른 사람에게 공유하지 마세요.


5. 가장 쉬운 소싱 방법: 홈 화면
------------------------------
1) [홈]으로 이동합니다.
2) 원하는 플랫폼을 아이콘 버튼으로 선택합니다.
3) 검색어를 입력합니다.
   예:
   - 기름 얼룩 제거제
   - 욕실 물때 제거
   - 주방 정리함
   - 휴대용 미니 세탁기
4) [검색하기]를 누릅니다.
5) 프로그램이 소싱 화면으로 이동합니다.
6) Gemini 또는 규칙 기반으로 플랫폼별 검색어를 만듭니다.
7) Chrome Bridge 연결 상태라면 후보 수집 작업까지 이어집니다.
8) 수집된 후보는 홈/소싱 화면에 표시됩니다.


6. 소싱 화면 상세 사용법
-----------------------
6-1. 상품명
- 직접 상품명을 입력합니다.
- [AI 검색어 생성]을 누르면 플랫폼별 검색 계획이 만들어집니다.

6-2. 쿠팡/상품 URL
- 현재 UI에서 상품 URL을 기록할 수 있습니다.
- 쿠팡 API 검색은 아래의 상품명 검색값을 기준으로 수행합니다.

6-3. 플랫폼 선택
지원 UI
- TikTok
- YouTube
- Instagram
- Douyin
- Xiaohongshu
- Kuaishou
- 1688

파란색으로 선택된 플랫폼만 검색/수집 대상으로 사용됩니다.

6-4. 검색 계획
- AI 검색어 생성 후 플랫폼별 검색어가 JSON 형태로 표시됩니다.
- Gemini 사용 시 플랫폼 특성에 맞게 영어/중국어 검색어를 만들도록 요청합니다.
- Gemini Key가 없거나 오류가 발생하면 규칙 기반 검색어로 폴백합니다.

6-5. 검색 페이지 열기
- 선택한 플랫폼의 첫 번째 검색어를 브라우저에서 직접 엽니다.
- 로그인이나 CAPTCHA가 필요한 플랫폼은 브라우저에서 직접 처리할 수 있습니다.

6-6. Chrome Bridge 자동수집
- 선택 플랫폼별 검색어를 Bridge 작업으로 보냅니다.
- 프로그램은 일정 시간 동안 확장 프로그램 결과를 기다린 뒤 후보 목록에 표시합니다.

6-7. 수집된 영상 목록
후보를 클릭하면
- 선택 후보 URL
- 선택 후보 제목
이 입력칸에 들어갑니다.

6-8. 유사도 계산
- 상품명과 후보 제목을 토큰 기준으로 비교합니다.
- 결과는 0~100%로 표시됩니다.
- 제목 정보가 부실한 영상은 유사도가 낮게 나올 수 있습니다.

6-9. 선택 영상 다운로드
- yt-dlp를 사용해 선택 URL의 영상을 다운로드합니다.
- 사이트 정책/로그인/DRM/지역 제한 등에 따라 실패할 수 있습니다.
- 다운로드 성공 시 해당 영상이 이후 편집/미리보기의 현재 영상으로 설정됩니다.


7. 쿠팡 API 검색
----------------
사용 조건
- 설정에 Coupang Access Key와 Secret Key가 있어야 합니다.

사용 방법
1) 소싱 화면의 상품명에 검색어를 입력합니다.
2) [쿠팡 API 검색]을 누릅니다.
3) 쿠팡 상품명/상품 URL/상품 이미지 정보를 후보 형태로 받아옵니다.

오류 메시지
- '쿠팡 Access/Secret Key를 설정하세요.'
  → 설정 화면에 키를 입력하고 저장하세요.


8. 편집 화면
------------
편집 화면은 다운로드한 영상 또는 직접 선택한 로컬 영상을 대상으로 사용합니다.

주요 흐름
1) 원본 영상 선택
2) OCR 자막 분석
3) 자막 정리
4) 필요 시 자동 컷
5) TTS 결합
6) 1080×1920 최종 렌더
7) 워터마크 적용

현재 자막 정리는 영상 하단 영역을 블러 처리하는 방식입니다.
정교한 오브젝트 인페인팅 방식은 아닙니다.


9. OCR / 자막 탐지
-----------------
NovaShorts에는 Tesseract OCR과 다음 언어 데이터가 포함됩니다.
- 한국어 kor
- 중국어 간체 chi_sim
- 영어 eng

동작 개요
- FFmpeg로 영상을 일정 간격의 프레임으로 추출
- 각 프레임을 Tesseract로 읽음
- 중국어 글자가 포함됐는지도 기록

하단 상태에 아래가 정상으로 보이면 기본 도구가 잡힌 것입니다.
- ffmpeg:정상
- ffprobe:정상
- tesseract:정상
- yt_dlp:정상
- chrome_bridge:정상


10. 자막 제거 ON/OFF
-------------------
오른쪽 빠른 설정에서 [자막 제거 (OCR)] 버튼을 눌러 ON/OFF할 수 있습니다.

ON
- 편집 흐름에서 OCR/자막 정리 단계를 사용

OFF
- 자막 정리 단계를 사용하지 않는 용도

주의
- 현재 제거 방식은 하단 영역 블러 기반이므로 자막 위치가 영상 중앙/상단이면 별도 조정이 필요할 수 있습니다.


11. 자동 컷 편집 ON/OFF
----------------------
ON
- 영상 길이를 여러 구간으로 나눠 세로형 쇼츠 구성을 만들 때 자동 컷 기능을 사용

OFF
- 자동 컷을 사용하지 않고 원본 흐름을 유지

자동 컷 모듈은 FFmpeg 기반으로 구간을 추출하고 이어붙입니다.


12. AI 음성
-----------
기본 TTS
- Edge TTS - SunHi

선택 가능한 음성
- SunHi
- InJoon
- Hyunsu

사용 방법
1) [AI 음성] 메뉴로 이동
2) 대본 입력
3) 음성 선택
4) TTS 생성
5) 생성된 오디오 파일을 편집/렌더에 사용

인터넷 연결이 필요합니다.


13. 세로형 최종 렌더
-------------------
기본 출력
- 1080 × 1920
- 세로형 쇼츠 비율

영상 비율이 다를 경우
- 원본 비율을 유지하며 축소/확대
- 남는 영역은 검은 패딩으로 채움

TTS 오디오가 지정된 경우
- 영상과 TTS를 함께 렌더
- 현재 설정은 짧은 쪽에 맞춰 종료되도록 구성됩니다.


14. 워터마크
------------
빠른 설정에서 ON/OFF할 수 있습니다.

실제 워터마크 텍스트/위치 설정값은 settings.json의 관련 필드를 사용합니다.
기본 위치
- bottom_right

지원 위치 코드
- bottom_right
- bottom_left
- top_right
- top_left
- center


15. 썸네일 만들기
-----------------
1) [썸네일] 메뉴로 이동
2) 영상 경로 입력
3) 썸네일 문구 입력
4) 저장 파일 경로 확인
5) [썸네일 만들기] 실행

생성 방식
- 영상의 프레임 추출
- 1080×1920 캔버스에 맞춤
- 문구를 오버레이
- JPG 저장


16. YouTube 업로드
-----------------
준비
1) Google Cloud에서 프로젝트 생성
2) YouTube Data API v3 활성화
3) OAuth 클라이언트 유형을 데스크톱 앱으로 생성
4) client_secret.json 다운로드
5) NovaShorts 설정의 'YouTube client_secret.json'에 파일 경로 입력

업로드
1) [업로드] 메뉴
2) 영상 경로
3) 제목
4) 설명
5) 태그
6) 공개 상태 선택
   - private
   - unlisted
   - public
7) [YouTube 업로드]
8) 브라우저에서 Google OAuth 승인을 완료

주의
- 첫 OAuth 과정에서 브라우저가 열립니다.
- 본인이 업로드 권한을 가진 YouTube 계정을 선택하세요.


17. Lnk.Bio
-----------
준비
- Client ID
- Client Secret

사용
1) [링크 관리]
2) 링크 제목 입력
3) 상품 링크 입력
4) [Lnk.Bio 추가]

빠른 설정의 [업로드 후 링크 생성] ON/OFF는 자동 링크 게시 설정값과 연결됩니다.


18. X 작성창
------------
1) [링크 관리]
2) X 게시문 입력
3) [X 작성창 열기]
4) 브라우저의 X 작성 화면이 열립니다.
5) 실제 게시 버튼은 사용자가 직접 확인 후 누릅니다.


19. 미리보기
------------
오른쪽 [미리보기] 영역에서 현재 선택/완성 영상을 확인합니다.

[파일 열기]
- PC에 있는 영상 직접 선택

[재생]
- 선택한 영상 재생/일시정지 용도


20. 작업 대기열
--------------
아래 작업 대기열에는 비동기 작업이 기록됩니다.
예:
- AI 검색어 생성
- 플랫폼 후보 수집
- 다운로드
- OCR
- TTS
- 렌더
- 업로드

버튼
- 모두 시작: 새 작업 시작 허용
- 모두 중지: 새 작업 시작을 막음
- 목록 비우기: 작업 기록 테이블 초기화

주의
- '모두 중지'는 이미 실행 중인 외부 FFmpeg/네트워크 작업을 즉시 강제 종료하는 기능이 아닙니다.
- 현재 실행 중인 작업은 완료된 뒤 정지 상태가 적용될 수 있습니다.


21. 런타임 진단
---------------
[설정] → [런타임 진단]

정상적으로 포함/발견돼야 하는 항목
- ffmpeg
- ffprobe
- tesseract
- yt_dlp
- chrome_bridge

문제가 있으면 [다시 진단]을 눌러 확인합니다.


22. 로그 확인
------------
문제가 생기면 아래 로그를 먼저 확인하세요.

C:\Users\사용자이름\.novashorts\logs\novashorts.log

오류 문의 시 도움이 되는 정보
- NovaShorts 버전
- 어떤 메뉴/버튼을 눌렀는지
- 오류창 전체 문구
- 로그 마지막 20~50줄
- 가능하면 문제 화면 캡처

API Secret, OAuth 토큰, bridge_token은 보내지 마세요.


23. 자주 발생하는 문제
---------------------
Q. 후보가 0개입니다.
A.
- Chrome Bridge 연결 확인
- 플랫폼에서 직접 로그인 확인
- 검색어를 더 짧게 변경
- 최소 유사도를 낮춤
- '저유사도 자동 제외'를 잠시 해제
- 검색 페이지 열기로 결과가 실제 존재하는지 확인

Q. Gemini 검색어 생성이 안 됩니다.
A.
- Gemini API Key 확인
- 네트워크 확인
- 빠른 설정에서 규칙 기반으로 바꿔 사용 가능

Q. 쿠팡 API 검색 오류
A.
- Access Key/Secret Key 확인
- 설정 저장 여부 확인

Q. 영상 다운로드 실패
A.
- URL이 실제 영상 상세 페이지인지 확인
- 플랫폼 로그인 필요 여부 확인
- 해당 플랫폼이 yt-dlp에서 현재 지원되는지 확인
- DRM/지역 제한 영상은 다운로드되지 않을 수 있음

Q. OCR 결과가 부정확합니다.
A.
- 자막이 너무 작거나 흐린 영상은 인식률이 떨어질 수 있음
- 현재 OCR은 Tesseract 기반

Q. 자막 제거 결과가 완벽하지 않습니다.
A.
- 현재 방식은 하단 블러 방식입니다.
- 자막 위치/배경에 따라 흔적이 남을 수 있습니다.

Q. YouTube 업로드 시 브라우저 인증이 뜹니다.
A.
- 정상적인 OAuth 절차입니다.
- 사용할 YouTube 계정을 직접 승인하면 됩니다.

Q. UI가 작거나 잘려 보입니다.
A.
- Windows 디스플레이 배율이 125%/150%인 경우 v1.15는 오른쪽 빠른 설정 높이를 자동 계산하고 설정/소싱 그룹에 여백을 추가해 이전보다 안전하게 표시되도록 수정돼 있습니다.
- 그래도 문제가 남으면 전체 화면 캡처와 Windows 배율(100/125/150%)을 함께 확인하세요.


24. 추천 테스트 순서
-------------------
처음에는 모든 기능을 한 번에 쓰지 말고 아래 순서로 확인하는 것이 좋습니다.

1) 설정 저장
2) 런타임 진단 전부 정상 확인
3) Chrome Bridge 연결
4) 규칙 기반 검색어로 소싱 테스트
5) 후보 1개 선택
6) 다운로드
7) 미리보기
8) OCR 테스트
9) Edge TTS 테스트
10) 1080×1920 렌더
11) 썸네일
12) 테스트용 private YouTube 업로드
13) 필요 시 Gemini / 쿠팡 / Lnk.Bio 연동 추가


25. 현재 버전에서 알아둘 점
---------------------------
- 플랫폼 웹사이트 구조는 수시로 바뀔 수 있으므로 브리지 수집 결과가 항상 동일하지는 않습니다.
- 후보 유사도는 현재 제목/키워드 중심 점수이며 이미지 임베딩 기반 정밀 상품 동일성 판정은 아닙니다.
- 자막 제거는 현재 하단 블러 방식입니다.
- YouTube 업로드는 단일 OAuth 업로드 흐름입니다.
- 로그인/회원가입/구독 기능은 NovaShorts에 포함하지 않았습니다.
