NovaShorts v1.20 사용설명서
============================

1. 가장 빠른 사용법
------------------
1) NovaShorts.exe 실행
2) Chrome 확장 프로그램 관리에서 ZIP 안의 browser-extension 폴더를 '압축해제된 확장 프로그램을 로드'로 등록
3) NovaShorts Bridge 팝업에서 프로그램의 Bridge 토큰을 연결
4) 소싱 화면에서 상품명 또는 쿠팡/상품 URL 입력
5) '상품부터 전체 자동 제작' 클릭
6) 자동으로 아래 순서가 진행됨
   상품 분석 → 7개 플랫폼 검색어 생성 → 관련 영상 수집 → 관련도 1위 선택 → 다운로드
   → OCR 검사 → 번인 자막 스마트 제거 → Whisper 음성 분석 → 한국어 쇼츠 대본 생성
   → Edge TTS + 한국어 자막 타이밍 → 장면 기반 자동 컷 → 1080x1920 렌더
   → 한국어 자막 삽입 → 선택 시 워터마크 → 썸네일 → 게시 메타데이터 생성
7) 결과는 설정의 출력 폴더 아래 NovaShorts_YYYYMMDD_HHMMSS 폴더에 저장

2. 쿠팡 API
-----------
쿠팡/상품 URL 분석과 영상 소싱에는 쿠팡 API 키가 필수가 아님.
Access Key / Secret Key는 '쿠팡 API 보강'을 사용할 때만 필요.

3. 플랫폼
---------
TikTok / YouTube / Instagram / Douyin / Xiaohongshu / Kuaishou / 1688
플랫폼 버튼으로 수집 대상을 선택할 수 있음.

4. 원클릭 자동 제작에서 실제 연결된 기능
-----------------------------------------
- 상품명/브랜드/모델/대표 이미지 분석
- Gemini 또는 규칙 기반 다국어 검색어 생성
- Chrome Bridge 기반 공개 검색 결과 수집
- 제목/모델/브랜드 관련도 정렬
- 대표 이미지/썸네일이 가능한 경우 이미지 유사도 보강
- yt-dlp 다운로드
- 다운로드 실패 시 Chrome Bridge 공개 미디어 URL 추출 폴백
- Tesseract OCR 검사(중국어 간체/한국어/영어)
- OpenCV 기반 번인 자막 영역 탐지 + 인페인팅 제거
- faster-whisper 음성 전사
- Gemini 한국어 대본 생성(키가 없으면 로컬 규칙 폴백)
- Edge TTS
- TTS 자막 타이밍(SRT)
- FFmpeg 장면 변화 기반 자동 컷
- 1080x1920 세로 렌더
- 한국어 자막 자동 삽입
- 워터마크
- 썸네일 자동 생성
- YouTube 메타데이터 자동 작성
- YouTube 업로드(설정에서 ON일 때만)
- Lnk.Bio 링크 생성(설정에서 ON일 때만)
- X 게시문 작성창 열기

5. 빠른 설정
------------
자막 제거 (OCR): ON이면 원클릭 제작에서 스마트 자막 제거 실행
자동 컷 편집: ON이면 장면 기반 자동 컷 실행
워터마크 추가: ON + 워터마크 문구 설정 시 적용
업로드 후 링크 생성: ON + Lnk.Bio 설정 완료 시 상품 링크 생성

6. 설정 > 원클릭 자동 제작 / AI 분석
------------------------------------
Whisper 음성 분석: base 내장 모델 사용
TTS 속도: -10%, 0%, +10%, +20%
목표 길이: 기본 20초
한국어 자막 자동 삽입: ON/OFF
썸네일 자동 생성: ON/OFF
YouTube 자동 업로드: 기본 OFF. 사용자가 ON으로 바꾼 경우에만 외부 업로드
Lnk.Bio 자동 링크: 기본 OFF

7. 수동 편집 기능
----------------
원클릭을 쓰지 않아도 각 메뉴의 버튼이 실제 기능과 연결되어 있음.
편집 메뉴: OCR 스캔 / 스마트 자막 제거 / 장면 기반 자동 컷 / 최종 렌더
AI 음성: 한국어 대본 입력 후 TTS + SRT 생성
썸네일: 현재 영상 프레임으로 썸네일 생성
업로드: YouTube 수동 업로드
링크 관리: Lnk.Bio 수동 추가 / X 게시창 열기

8. Chrome Bridge 업데이트
-------------------------
v1.19 이전 확장 프로그램이 설치되어 있다면 ZIP의 browser-extension 폴더로 다시 로드해야 함.
확장 프로그램 개발자 모드 → NovaShorts Bridge의 새로고침 아이콘 클릭 또는 기존 항목 제거 후 재등록.

9. 결과 파일
------------
01_subtitle_clean.mp4 : 자막 제거 결과
transcript.json        : Whisper 분석
script.txt             : 한국어 대본
02_tts.mp3             : 한국어 TTS
02_korean.srt          : 한국어 자막 타이밍
03_auto_cut.mp4        : 장면 기반 자동 컷
04_final_short.mp4     : 최종 쇼츠
05_final_watermark.mp4 : 워터마크 적용 시 최종본
thumbnail.jpg          : 썸네일
publish_metadata.json  : 제목/설명/태그
result.json            : 전체 실행 결과

10. 참고
--------
플랫폼 로그인 상태, 지역 제한, CAPTCHA, 공개 페이지 구조 변경에 따라 일부 영상은 수집 또는 다운로드가 실패할 수 있음.
NovaShorts는 계정 인증 우회나 CAPTCHA 우회를 하지 않음.
